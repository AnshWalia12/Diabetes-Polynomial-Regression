# Diabetes Prediction using Polynomial Regression

ML project built using Streamlit and Polynomial Regression on Kaggle Diabetes Dataset.

## Features

- Diabetes prediction
- Polynomial Regression
- Interactive Streamlit UI
- Dataset visualization
- Prediction score

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## Run Locally

Install requirements:

pip install -r requirements.txt

Train model:

python train_model.py

Run app:

streamlit run app.py
